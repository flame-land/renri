Getting started

Setup

Add Renri to a server, check its permissions, then start with the command docs.

  1. Invite Renri

    Use the invite link and choose the Discord server where you want to install Renri.

  2. Review permissions

    Grant only the permissions Renri's enabled features need. Moderation commands may require elevated permissions.

  3. Test the bot

    Run /help or check the command reference to get started.
